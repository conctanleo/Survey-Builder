# 语音问卷 Web App 前端设计规格

## 概述

面向学术研究场景的语音问卷 Web App 前端。用户通过扫描二维码进入问卷，默认以语音录音方式回答问题，录音文件存储在后台。支持语音录音题（核心）、单选/多选题、文字填空题三种题型。

## 技术栈

参考卷王（SurveyKing）技术栈：

| 层级 | 选型 |
|------|------|
| 框架 | React 18+ |
| 构建工具 | Vite |
| UI 组件库 | Ant Design 5.x |
| 路由 | React Router 6 |
| 状态管理 | Zustand（轻量，适合问卷状态） |
| 样式方案 | CSS Modules + Ant Design Token 主题系统 |
| 录音 | MediaRecorder API（浏览器原生） |
| HTTP | Axios |

## 页面流程

```
扫码 → 页面1: 信息采集 → 页面2: 问卷欢迎 → 页面3: 答题 → 页面4: 完成确认
```

### 页面 1：信息采集页

**目的：** 采集受访者个人信息（姓名、手机号等，字段由管理员配置）

**UI 设计：**
- 背景：温暖紫渐变 `linear-gradient(160deg, #4f46e5, #7c3aed, #a855f7)`
- 表单卡片：毛玻璃效果 `backdrop-filter: blur(20px)`，`background: rgba(255,255,255,0.12)`，圆角 20px
- 输入框：半透明底色 `rgba(255,255,255,0.1)`，圆角 12px，白色文字
- 标签：12px 大写字母，`rgba(255,255,255,0.6)`
- CTA 按钮：白色背景，紫色文字 `#4f46e5`，圆角 14px，全宽
- 装饰：右上角和左下角半透明圆形
- 底部隐私提示文字 `rgba(255,255,255,0.4)`

**交互：**
- 表单验证：必填项校验
- 点击 "进入问卷" 跳转欢迎页
- 表单字段从后台配置读取，非硬编码

### 页面 2：问卷欢迎页

**目的：** 展示问卷标题、说明、预估信息，用户确认后开始答题

**UI 设计：**
- 背景：清新绿渐变 `linear-gradient(160deg, #059669, #10b981, #34d399)`
- 顶部：文档图标 + 问卷标题（24px 粗体）+ 说明文字
- 三栏信息卡（毛玻璃）：题目数 / 预计时长 / 语音回答提示
- 温馨提示卡：带图标，提醒用户在安静环境录音
- CTA 按钮：白色背景，深绿文字 `#059669`
- 装饰圆形同页面 1

**数据来源：** 问卷标题、描述、题数、预计时长均从后台 API 获取

### 页面 3：答题页

**目的：** 核心答题页面，支持三种题型，支持单题分页和连续滚动两种模式（管理员可配置）

**UI 设计：**
- 背景：温暖紫渐变（同页面 1）
- 顶部进度条：`rgba(255,255,255,0.15)` 底色，白色填充，4px 高度
- 题号/题型标注：12px，`rgba(255,255,255,0.5)`
- 题目文字：20px 粗体，居中
- 底部导航：上一题 / 下一题

**三种题型的交互设计：**

#### 语音录音题（核心题型）
- **待录音状态：** 紫色渐变圆形按钮（72px），麦克风图标，下方 "点击开始录音" 文字
- **录音中状态：**
  - 按钮变为红色渐变 `linear-gradient(135deg, #ef4444, #dc2626)`
  - 脉冲动画：两层圆环从按钮向外扩散，1.5s 循环
  - 波形可视化：15 条竖线，`rgba(255,255,255,0.3~0.7)`，高度随机
  - 计时器：22px 粗体，格式 MM:SS
  - 暂停图标替换麦克风图标
- **录音完成状态：** 绿色对勾，显示录音时长，可重录

#### 单选/多选题
- 选项为半透明卡片：`background: rgba(255,255,255,0.1)`，圆角 14px，内间距 16px
- 未选中：细边框 `1.5px solid rgba(255,255,255,0.15)`
- 选中态：白边框 + 加粗文字 + `box-shadow: 0 0 16px rgba(255,255,255,0.1)`
- 单选：圆形 radio 指示器（选中时粗白边）
- 多选：方形 checkbox 指示器

#### 文字填空题
- 毛玻璃输入框，同信息采集页风格
- 多行文本域，圆角 12px

**题目展示模式（管理员可配置）：**
- **单题分页模式：** 一屏一题，题号 + 进度条，上下题导航
- **连续滚动模式：** 所有题目纵向排列，底部固定提交按钮

### 页面 4：提交完成页

**目的：** 确认提交成功，展示统计摘要

**UI 设计：**
- 背景：温暖紫渐变（同页面 1）
- 大号对勾图标（96px 毛玻璃圆形）+ "提交成功" 标题（26px）
- 感谢文字
- 统计卡（毛玻璃）：已答题目 / 用时 / 语音回答数，三栏均分
- 散落彩色圆点装饰（黄、粉、蓝、绿、紫，6-8 个，8-10px）
- 隐私提示条：小图标 + "已加密保存，仅用于研究"
- 关闭按钮：半透明 `rgba(255,255,255,0.15)`，非强 CTA

### 核心组件说明

**VoiceRecorder（语音录音组件）：**
- 使用浏览器原生 `MediaRecorder API` 采集音频
- 状态机：idle → recording → paused → completed
- 录音文件格式：WebM（浏览器默认），上传时转为 Blob
- 音频可视化：基于 `AnalyserNode` 实时绘制波形
- 最大录音时长可配置（默认 5 分钟）

**surveyStore（问卷状态）：**
- 当前页码 / 题目索引
- 用户答案 Map（题目ID → 答案数据）
- 录音文件 Map（题目ID → Blob）
- 用户个人信息
- 问卷配置（分页模式 / 主题色等）

## 录音技术方案

| 项目 | 方案 |
|------|------|
| 采集 API | `navigator.mediaDevices.getUserMedia` + `MediaRecorder` |
| 音频格式 | WebM/Opus（Chrome/Firefox 原生），Safari 用 AAC |
| 可视化 | `AudioContext` + `AnalyserNode` + Canvas/SVG |
| 文件大小 | 预估 ~1MB/分钟（Opus 128kbps） |
| 上传方式 | 每题录音完成后异步上传，不阻塞答题流程 |
| 权限处理 | 首次录音弹出麦克风权限请求，拒绝时显示引导提示 |

## 响应式设计

- **主要目标：** 移动端（390×844 基准）
- **适配范围：** 320px ~ 428px 宽度
- 单题分页模式下内容垂直居中
- 录音按钮、选项卡片等触控区域 ≥ 44px

## 无障碍

- 录音按钮提供 `aria-label` 状态描述
- 选项支持键盘导航（Tab + Enter/Space）
- 进度信息通过 `aria-live` 区域播报
- 对比度符合 WCAG AA 标准（白色文字在渐变背景上）
